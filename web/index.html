What these scores mean

Content scores use TF-IDF on fictional metadata and price/category similarity. Collaborative scores use cosine similarity of fictional binary co-interactions. These are similarity scores, not probabilities. The hybrid's default is 0.6 × collaborative + 0.4 × content; weight changes are exploratory and not evidence of optimization.

ARCHITECTURE AND REPRODUCIBILITY

Transparent by design.

No server, API key, database, cookie banner, paid inference, analytics service or login. Synthetic interactions and metadata are generated deterministically in the browser.

01 / CONTENT

Text and metadata

Product-name and description TF-IDF; category and price compatibility; cosine similarity.

02 / COLLABORATIVE

Co-interaction similarity

Binary user-item incidence, item-item cosine; undefined behavior falls back to popularity.

03 / RE-RANKING

Constraints and diversity

Unseen-item exclusion, availability, budget/category filters, greedy redundancy penalty.

04 / EVIDENCE

Independent audit layer

Fixed, aggregated numbers from the private research snapshot; no original user identifiers are published.

Deployment architecture

Local research → aggregated benchmark record
Synthetic generator → client-side ranking engine → GitHub Pages
Test suite → GitHub Actions → reviewable pull requests

Synthetic interaction outcomes are not an estimate of real-world lift. An improved genuine benchmark would use independently licensed per-user ratings and timestamps with chronological splits and confidence intervals.
